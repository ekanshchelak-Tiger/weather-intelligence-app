# Weather Intelligence App 🌤️

A responsive, modern Weather Intelligence App built with React, Vite, and Tailwind CSS using AI-assisted development in Google AI Studio App Build.

## 🚀 Live Demo
- **Live Cloudflare Pages URL:** https://weather-intelligence-app.ekansh-chelak.workers.dev/
- **GitHub Repository:** https://github.com/ekansh-chelak/weather-intelligence-app

---

## 🛠️ Features
- **City Search:** Geocoding integration via Open-Meteo Geocoding API to search cities worldwide.
- **Current Weather:** Live temperature, humidity, wind speed, and current weather condition status.
- **7-Day Forecast:** Detailed 7-day daily weather forecast cards.
- **Visual Analytics:** Temperature trend charts for daily maximum and minimum temperatures.
- **Smart Recommendations:** Contextual planning and attire recommendations based on real-time weather metrics.
- **Error Handling:** Graceful error fallback for invalid city searches or API network errors.

---

## 🔌 API Endpoints Used (Open-Meteo)
1. **Geocoding API:** `https://geocoding-api.open-meteo.com/v1/search`
2. **Forecast API:** `https://api.open-meteo.com/v1/forecast`

## 💻 Local Setup & Development

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/ekansh-chelak/weather-intelligence-app.git](https://github.com/ekansh-chelak/weather-intelligence-app.git)
   cd weather-intelligence-app

2. Install dependencies:
   npm install

3. Run local development server:
   npm run dev

4. Build for production:
   npm run build
